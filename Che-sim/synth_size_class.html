サイズが 2〜3 個しかない合成トレースで、サイズ分類の効果を式で説明する

2026-11-05。生成器 tools/synth/synth_gen.c、理論 tools/synth/synth_model.c、実行 tools/synth/synth_run.py・run_all.sh、結果 tools/synth/results/。式の厳密な導出（仮定・補題・証明）は 付録。実測は libCacheSim（物単位 LRU）と RegionFlash（DRAM なし、全受け入れ、Region 256 個、先頭 25% で温め）。

要点
  1. 提案のやり方は妥当で、しかも 3 つのつまみが統計量に 1 対 1 で対応する：サイズの値は \(\mathrm{Var}(\log s)\)、要求の割合と物の数は「要求とバイトの偏り」、Zipf の傾きは \(\mathrm{Var}(\log\lambda)\) を動かす。ただし「要求の割合」と「物の数」は両方決める必要がある（物 1 個の \(\lambda=\text{割合}\div\text{物の数}\times\text{Zipf の重み}\)）。
  2. Che 近似に基づく式は 3 段で書け、どれも実測と合う。物単位 LRU と静的分割は誤差 0.3pt 以下（各 24 点、平均 0.01〜0.04pt）、Region FIFO は 0.2pt、Region LRU は立ち上がりの隔離（§5.4）を入れて OHR 平均 0.2pt・BHR 平均 0.1〜0.8pt。
  3. サイズで分けると、式は「\(T\) が 1 つ」から「クラスごとの \(T_k\)」に変わる。最適な \(T_k\) は「境目にある物の \(\lambda/s\)」がクラス間でそろう点（限界ヒット/バイトの均等化）。W1（36 KiB / 1 MiB、要求 3:1）では OHR +14〜18pt、BHR −14〜19pt。
  4. Region キャッシュでは、物から見ると「滞在 \(L\) の FIFO」になる。Region FIFO では \(L\) がどのクラスでも同じなので、分類しても利得は厳密に 0（実測でも ±0.3pt）。Region LRU では \(L_k=\int_0^T\mathbb{E}[e^{\Lambda t}]\,dt\) で、1 個の Region に小物が多く入るほど touch 率 \(\Lambda\) が上がり、寿命が指数的に延びる。これが「明示的に分割しなくても容量が小物に寄る」仕組み。
  5. 対照 W2（\(\lambda/s\) の分布を両クラスでそろえた）では利得がほぼ消える（静的分割 +0.7pt、Region LRU +0.5pt）。効いているのはサイズそのものではなく価値 \(\lambda/s\) のばらつき、という trace_characteristics.md §8 の予想どおり。
  6. Region LRU の定常モデルは、サイズ分類時の BHR を過小に出していた（平均 3.5pt、W3 で最大 14pt）。根本原因は「立ち上がりの隔離」（§5.4）：空のキャッシュを埋める間は全部がミスなので、最初の Region には熱い物・温かい物がまとめて詰まり、\(\Lambda\) が非常に大きくなって事実上不死になる。熱い物はそこに隔離されて二度とミスせず、冷たい物の Region を守らなくなる。定常（エルゴード）を仮定したモデルは、この準安定な状態を表せなかった。初期の詰め込みを再現して「観測期間を生き延びる初期 Region は不死」とする項を入れると（-H）、Region LRU（サイズ分類）の BHR の誤差は平均 3.5 → 0.8pt、最大 14.4 → 2.6pt に下がり、Region 数を変えても実測に追従する。当初の診断「\(T\) の揺らぎが主因」は誤りで、撤回。
  7. 人気が変わると隔離は消える（§6）：一巡時間がトレース長の 4 倍のゆっくりした老化でも、立ち上がりの Region は 1 個も残らない。代わりに、熱い新顔が入った「生まれた時に熱い Region」が流れ続ける。老化による OHR の損失は Region キャッシュの方が物 LRU より 2〜4 倍大きいが、サイズ分類の利得は老化があっても残る（W1 30% で +13〜17pt）。

1. 提案の妥当性

提案の段階評価注意・直し方
① サイズの数と値（例 36 KiB と 1 MiB）妥当。\(\mathrm{Var}(\log s)\) を自由に動かせ、実トレースの「サイズの寄与」と同じ軸に置けるRegionFlash の piece-wise（chunk=1M）の境目を避ける。今回は chunk を切った。CacheLib に流すときは小物が BigHash に行かない設定にする
② 要求の割合 か ユニーク数の割合どちらか一方では足りない。物 1 個の \(\lambda\) は「割合 ÷ 物の数」で決まり、価値 \(\lambda/s\) の分布はその両方に依る(物の数, 要求の割合, \(\alpha\)) の 3 つを指定する形にした（size:nobj:share:alpha）。3:1 と 6:1 では利得はほぼ同じ（10% で +15.8 と +16.6pt）。効くのは比そのものより \(\lambda/s\) の分布
③ サイズごとの Zipf の傾き妥当。クラス内の \(\mathrm{Var}(\log\lambda)\) を動かせる傾きが急なクラスは Region の \(\Lambda\) が大きく、Region LRU のモデルの誤差が増える（§4）
IRM（独立参照）で作ることChe 近似の前提とちょうど一致するので、「式で説明できるか」を確かめる目的には最適時間局所性・一回きりの物・サイズ変化（block で 41%）は含まれない。実トレースとの差はこれらの寄与として別に測る
必要な対照W2（\(\lambda/s\) をそろえる）、Region FIFO（分類が効かないはず）を入れたW3（無作為な 2 分割）は IRM では Region FIFO と同じ理屈で 0 になるので省いた

2. 定式化：Che 近似から 3 段で

2.1 物単位 LRU（共有）と静的分割

時間の単位を要求 1 回にして、物 \(i\) の要求率を \(\lambda_i\)（\(\sum_i \lambda_i = 1\)）、大きさを \(s_i\)、在籍率（＝ヒット率）を \(h_i\)、容量を \(C\) とする。

共有（\(T\) は 1 つ）

\[ h_i = 1 - e^{-\lambda_i T}, \qquad \sum_i s_i\, h_i = C \]

クラスで静的に分割（\(T_k\) はクラスごと）

\[ h_i = 1 - e^{-\lambda_i T_k}\ \ (i \in k), \qquad \sum_{i \in k} s_i\, h_i = C_k, \qquad \sum_k C_k = C \]

OHR 最適の配分：クラス \(k\) のヒット数 \(H_k = \sum_{i\in k}\lambda_i h_i\) の、容量あたりの限界がすべてのクラスで等しい。

\[ \frac{\partial H_k}{\partial C_k} = \frac{dH_k/dT_k}{dC_k/dT_k} = \frac{\sum_{i \in k} \lambda_i^{2}\, e^{-\lambda_i T_k}}{\sum_{i \in k} s_i\, \lambda_i\, e^{-\lambda_i T_k}} \;\overset{s_i = s_k}{=}\; \frac{1}{s_k}\cdot \frac{\sum_{i \in k} \lambda_i^{2}\, e^{-\lambda_i T_k}}{\sum_{i \in k} \lambda_i\, e^{-\lambda_i T_k}} = \mu \quad (\text{全クラスで同じ}) \]

BHR 最適の配分：バイトのヒット \(B_k = \sum_{i\in k} s_i\lambda_i h_i\) で同じことをすると、\(1/s_k\) が消える。

\[ \frac{\partial B_k}{\partial C_k} = \frac{\sum_{i \in k} s_i\, \lambda_i^{2}\, e^{-\lambda_i T_k}}{\sum_{i \in k} s_i\, \lambda_i\, e^{-\lambda_i T_k}} \;\overset{s_i = s_k}{=}\; \frac{\sum_{i \in k} \lambda_i^{2}\, e^{-\lambda_i T_k}}{\sum_{i \in k} \lambda_i\, e^{-\lambda_i T_k}} = \mu' \]

注 1（\(s_i = s_k\) の意味）：今回の合成負荷では、クラス \(k\) を「サイズが \(s_k\) の物」と定義しているので、クラスの中の物はすべて \(s_i = s_k\)。\(\overset{s_i = s_k}{=}\) はこの条件のもとでの等号。サイズに幅のあるクラス（実トレースのサイズ帯など）では \(s_i\) を和の外に出せないので、左側の一般形を使う。
注 2（\(\lambda\) が約分できない理由）：分子・分母はともに、物ごとに \(\lambda\) の違う項の和なので、項どうしで約分できない（\(\sum a_i^2/\sum a_i \ne \sum a_i\)）。分子の \(\lambda_i^2\) は「ヒット 1 回の価値 \(\lambda_i\)」×「\(T\) を延ばしたときに在籍率が増える速さ \(\lambda_i e^{-\lambda_i T}\)」から来る。例：\(\lambda = 0.1, 0.01\)、\(T = 10\) なら、比は 0.003769 / 0.04584 = 0.082 で、0.01 と 0.1 の間の重み付き平均になる。

比 \(\sum\lambda_i^2 e^{-\lambda_i T_k} / \sum\lambda_i e^{-\lambda_i T_k}\) は、重み \(w_i \propto \lambda_i e^{-\lambda_i T_k}\) による \(\lambda\) の平均、つまり「LRU の境目にいる物の \(\lambda\) の重み付き平均」\(\bar\lambda_k\) なので、OHR 最適は境目の物の \(\lambda/s\) をクラス間でそろえること、BHR 最適は境目の \(\lambda\) をそろえることを意味する。共有 LRU は全員に同じ \(T\) を与えるので、境目の \(\lambda\) が自動的にそろい、BHR についてはほぼ最適になる。W1・容量 10% で比べると：

2.2 Region キャッシュ

Region を消すと中の物が全部消え、ヒットしても物は動かない。したがって物 \(i\) から見ると、「挿入されてから Region が消えるまで（\(L_i\)）」だけキャッシュにいる FIFO になる。再生報酬の定理から、次の式が成り立つ。

物から見た在籍率（滞在 \(L_i\) の FIFO。Che 近似の FIFO 版と同じ形）

\[ h_i = \frac{\lambda_i L_i}{1 + \lambda_i L_i} \]

Region FIFO：どの Region も封じてから同じ時間 \(T\) で消えるので、分類しても \(h_i\) は変わらない。

\[ L_i = T \]

Region LRU：Region は最後の touch から \(T\) 経つと消える。touch の率が一定の \(\Lambda\) なら、期待寿命は

\[ \mathbb{E}[\text{寿命}] = \frac{e^{\Lambda T} - 1}{\Lambda} = \int_0^{T} e^{\Lambda t}\, dt \]

物 \(i\) が入った Region の \(\Lambda\) は、自分の \(\lambda_i\) と同居の物の \(\lambda_j\) の和。同居の物を挿入の流れから独立に引くと

\[ L_i = \int_0^{T} e^{\lambda_i t}\; \mathbb{E}\!\left[ \prod_{j \in \text{同居}} e^{\lambda_j t} \right] dt \]

単一サイズの分類 \(k\) なら、同居は \(n_k - 1\) 個（\(n_k = \lfloor R/s_k \rfloor\)）で、挿入はミス率 \(m_j\) に比例するので

\[ \mathbb{E}\!\left[ \prod_{j} e^{\lambda_j t} \right] = M_k(t)^{\,n_k - 1}, \qquad M_k(t) = \frac{\sum_{j \in k} m_j\, e^{\lambda_j t}}{\sum_{j \in k} m_j}, \qquad m_j = \frac{\lambda_j}{1 + \lambda_j L_j} \]

容量の条件（\(\phi_k\) は Region の充填率。詰め残しも容量を食う）

\[ \sum_i \frac{s_i\, h_i}{\phi_{k(i)}} = C \]

補正：封じるまでの待ち \(U_k\) を滞在に足す（\(L_i \leftarrow U_k + L_i\)、\(U_k\) は「後から入る物の数の平均 \((n_k-1)/2\)」÷「分類の挿入率」）。立ち上がりの初期 Region \(j\) のうち、寿命が観測期間 \(H\) を超えるもの（\((e^{\Lambda_j T}-1)/\Lambda_j > H\)）は不死とし、その中の物は \(h_i = 1\)（§5.4）。

挿入の流れが \(L\) に依るので、\(T\) ごとに不動点を解き、占有が \(C\) になる \(T\) を二分法で求める。この式のもとでは、サイズ分類の効果は次のように説明できる。

サイズ分類 = Region の「touch 密度」の分離
Region の touch 率は \(\Lambda\approx(R/s_k)\,\mathbb{E}_{\rm ins}[\lambda]\)、つまり \(R\times\mathbb{E}_{\rm ins}[\lambda/s]\)（挿入された物の \(\lambda/s\) の平均） で、Region 1 個の価値密度そのものである。混ぜると全 Region の \(\Lambda\) がならされるが、分けると小物の Region だけ \(\Lambda\) が大きくなり、寿命 \((e^{\Lambda T}-1)/\Lambda\) が指数的に延びる。LRU は寿命の差で容量を配り直すので、静的分割の \(C_k\) を明示的に決めなくても、容量が価値密度の高い側へ寄る（W1・容量 10% で小物の容量は 13% → 62%）。FIFO はこの寿命の差を作れないので、分類は効かない。

4.1 読み取り

  • 式が合う範囲：物単位 LRU と静的分割は 48 点すべてで誤差 0.3pt 以下。Region FIFO の分類なしは、混在 Region の詰め残しの影響で最大 0.9pt。Region LRU は立ち上がりの隔離（§5.4）を入れたモデルで、OHR 平均 0.2pt、BHR 平均 0.1pt（分類なし）・0.8pt（サイズ分類）。
  • 静的分割の利得は Region LRU の分類で大半を取り戻せる：W1 の \(\Delta\)OHR は、静的分割 +14〜18pt に対して Region LRU の分類が実測 +10〜16pt。しかも BHR の悪化は半分ほどで済む（−2〜−8pt 対 −14〜−19pt）。Region LRU は、分割の最適点まで振り切らない。
  • W2 の対照：利得は静的分割 +0.7pt、Region LRU +0.5pt に縮む。0 にならないのは、共有 LRU の価値の順位が \(\lambda\) だけで決まり、\(\lambda/s\) が同じでも大物（\(\lambda\) が 28 倍）を優遇するため。
  • Zipf の傾き（W3・W3r）：小物の傾きを急にすると（W3）、小物の少数の熱い物で大半の要求をまかなえるので、分割の利得は小さい（10% で +10pt）。小物を平らにすると（W3r）、分割の利得は最大になる（20% で +27pt）。小物の価値が多くの物に薄く広がっている負荷ほど、サイズ分類が効く。
  • 3 サイズ（W5）：\(k=2\) の境目は 8K と 128K の間が良い（モデルでは、{8K}/{128K,1M} の Region LRU が 0.600、{8K,128K}/{1M} は 0.542。容量 10%）。\(k=3\) の上乗せは、最良の \(k=2\) に対してモデルで +1.8pt。近いサイズを分けても上乗せは小さく、最初の境目は「\(\lambda/s\) の差が一番大きい所」に置くのが良い。

5.1 補正の試み：追い出し年齢 \(T\) の揺らぎ

揺らぎの大きさの式（実測と合う）：Region LRU は「最後の touch が古い順」に追い出すので、追い出し年齢 \(T\) は待ち行列の待ち時間に当たる。到着（Region への最後の touch）はポアソン的で、退去（追い出し）は書いたバイト数で決まるのでほぼ規則的。\(T\) が伸びると、最後になるはずだった touch の前に再び touch される Region が増え、到着が減る。これが \(T\) を引き戻す力になり、Ornstein–Uhlenbeck 過程になる。不死の Region や touch のない Region も含めて整理すると、復元力は \(-a'(T)=\sum_i m_i\lambda_i\)（挿入される物の \(\lambda\) の流量）になり、

\[ \mathrm{sd}(T)=\frac{1}{\sqrt{2\sum_i m_i\lambda_i}}\qquad(\text{Region の大きさに依らない絶対量}) \] \[ \mathrm{CV}=\frac{\mathrm{sd}(T)}{T}\qquad(\text{Region を小さく・数を多くすると }T\text{ が伸びて CV が下がる}) \]

導出は 付録 §I。

寿命への効果（式を入れたが、既定にはしない）：無アクセス区間が、その時点の閾値 \(\Theta=T(1+\mathrm{CV}\cdot z)\) を超えたら死ぬとすると、1 区間で死ぬ確率は \(p=\mathbb{E}[e^{-\Lambda\Theta}]\)、寿命は \(L=(1/p-1)/\Lambda\)。Θ が一定なら \((e^{\Lambda T}-1)/\Lambda\) に戻る（synth_model -c <CV> または -c auto）。

5.4 根本原因：立ち上がりの隔離

計測：終了時に残っている全 Region を出す計測（RF_ENDDUMP）を足し、封じた全 Region の組成を調べた（tools/synth/clustering.py）。W3・20%・\(N=1024\) では、封じた後に追い出されずに残った小物の Region のうち、69 個が最初の 100 万要求で封じたもので、\(\Lambda T\) は 9〜4917 だった。順位 1〜99 の物は全部、100〜999 は 889/900 個がその中にいた。後から封じた Region の組成は iid（温かい物の個数の分散/平均 0.97）で、モデルの組成の仮定そのものは正しい。

モデルへの組み込み（synth_model -H <観測期間>）：

  1. 各物の初回の要求時刻 \(\tau_i\sim\mathrm{Exp}(\lambda_i)\) を引き、\(\tau\) の順に、分類ごとの Region に詰める（容量が埋まるまで）。
  2. 初期 Region \(j\) の寿命 \((e^{\Lambda_jT}-1)/\Lambda_j\) が観測期間 \(H\) を超えれば「不死」：中の物は在籍率 1 で、ミスしない。
  3. 残りの物と、残りの容量 \(C-N_{\rm imm}R\)（\(N_{\rm imm}\) は不死の Region の数）で、これまでの定常モデルを解く。
  4. 不死の判定は \(T\) に依るので、\(T\) と不死の集合を交互に解き直す。

充填期の終わりが Che の \(T\) と一致すること、生存確率 \(e^{-H/\mathbb{E}D}\) の根拠は 付録 §F・命題 E.2。

6. 人気が変わる負荷での隔離（11-05 追記）

6.1 分かったこと

  • 立ち上がりの隔離は、ゆっくりした老化でも完全に消える。\(\tau\) = 8,000 万（トレース長の 4 倍）でも、立ち上がりに封じた Region は終了時に 0 個（老化なしでは小物 26〜59 個）。100 万要求ごとのヒット率は最初の窓を除いて平らで、時間とともに損失が増えたり減ったりする過渡は見えない。立ち上がりの隔離が長く居座る、という形の損失は起きない。隔離は、人気が永遠に変わらない合成負荷に特有の現象。
  • 代わりに「生まれた時に熱い Region」が流れ続ける。新しい物は 1 位で入ってきて、最初の要求は必ずミスなので、挿入の流れには常に熱い新顔が混ざる。W1 30% では、生き残っている小物の Region の封じた時の \(\Lambda T\) は 500〜1000（老化なしでは 7）。その後、中の物が老化して今の \(\Lambda T\) は 8〜12 に下がるが、0.2〜4M 要求（\(T\) の数十〜千倍）生き続ける。
  • 老化の損失は Region キャッシュの方が大きい：W1 30% の OHR の損失は、物 LRU が −0.2 / −0.7 / −2.9pt（\(\tau\) = 8,000 万 / 2,000 万 / 500 万）に対して、Region LRU の分類ありは −0.8 / −2.6 / −6.2pt。物 LRU の損失は新しい物の初回ミスでほぼ説明できるので、差の 0.6〜3.3pt が Region に固有の損失。
  • モデルとの関係：老化があると、実測は定常モデルと隔離ありモデルの間に来る（\(\tau\) = 8,000 万で、W1 10% の BHR は定常モデルに一致、W1 30%・W3 は間）。どちらも「新しい熱い物の挿入」と「初回ミス」を含まないので、老化のある負荷を当てるには、この 2 つを足す必要がある。
  • 居座りを直接測る試み（不採用）：残っている Region の中で今の \(\lambda T\lt0.1\) の物の割合を測ったが、老化なしでも 0.93〜0.97 で差が出なかった。Region キャッシュでは物の滞在が \(T\) ではなく Region の寿命（\(T\) の数十〜千倍）で決まるため、\(T\) は物差しにならない。Region に固有の 0.6〜3.3pt の損失が居座りによるものかは、まだ確かめていない。

6.2 老化のモデル（tools/synth/synth_age.c、途中経過）

物を年齢 \(a\) で表す（順位 \(r=1+\lfloor a/P\rfloor\)、どの時点でも順位ごとに物が 1 個）。\(h(a)\) は年齢 \(a\) の物の在籍率。

物単位 LRU（生まれる前は \(\lambda=0\) なので、初回ミスが入る）

\[ h(a)=1-\exp\!\Big(-\int_{a-T}^{a}\lambda(u)\,du\Big) \]

Region LRU（再生方程式）

\[ h(a)=\int_0^a\lambda(a')\,\big(1-h(a')\big)\,G(a\mid a')\,da' \] \[ G(a\mid a')=\mathbb{E}_m\!\Big[\exp\Big(-\int_{a'}^{a}\eta\big(\lambda(u)+\Lambda_{\text{その他}}(u-a')+m\,\lambda_{\text{新顔}}(u-a')\big)\,du\Big)\Big],\qquad \eta(\Lambda)=\frac{\Lambda}{e^{\Lambda T}-1} \]

\(m\) は Region の中の熱い新顔の数で、\(m\sim\mathrm{Poisson}(\nu)\)。同居の物も一緒に老化する。\(\eta=1/\mathbb{E}D\) は寿命の式 \((e^{\Lambda T}-1)/\Lambda\) の逆数で、死亡率の平均場近似（付録 §J）。

  • 物単位 LRU：12 構成すべてで実測と 0.25pt 以内。初回ミスを含めて完成。
  • Region LRU：単一サイズ（\(\tau\) = 2,000 万）で −0.9pt、\(T\) は 3,745 対 3,752。W1 30% の分類ありは 3 段の \(\tau\) で OHR/BHR とも 1.9pt 以内、W3 20% の分類ありは 1.4pt 以内。
  • 新顔の数のばらつき：新顔は 1 Region に 0.25 個（混在・W1 10%）〜 60 個（分類あり・W1 30%）。少ないとポアソン的で、寿命は新顔 0 / 1 / 2 個で 11,949 / 45,846 / 97,149 要求（実測）。平均場で均すと全 Region が長生きになり、混在の最悪点は −18pt。ポアソンで平均すると −3pt に縮んだ。
  • 残る誤差（未解決）：容量 10% と分類なしの構成で、OHR が 9〜22pt 低く、\(T\) が実測の半分以下に解かれる。モデルは混在の Region で大物のミスを少なく見積もり、1 Region の物の数を約 440 個と数える（実測は約 40 個、ミスの 22% が大物）。大物の在籍率の求め方の見直しが次の作業。
評価への意味：老化のない合成負荷を空から始めると、立ち上がりの隔離が結果に入り込む（§5.4）。人気がわずかでも変われば隔離は消えるので、実トレースに近い条件を見たいなら、老化つきの負荷か、定常モデル（-H 0）を基準にする。サイズ分類の効果（分類あり − 分類なし）を老化つきで比べると、W1 30% で \(\tau\) = 8,000 万なら OHR +16.7pt（老化なし +15.7pt）、\(\tau\) = 500 万なら +13.4pt。サイズ分類の利得そのものは、老化があっても残る。
