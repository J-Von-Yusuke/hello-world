1. キャッシュとは

キャッシュは「よく使う物を、近くの小さな置き場に置いておく仕組み」である。図書館でたとえると、書庫（遠いが全部ある）と、机の上（近いが少ししか置けない）の関係に当たる。

  • 要求（リクエスト）：利用者が「この本（物）がほしい」と言うこと。
  • ヒット：机の上（キャッシュ）にあった。速い。ミス：なかったので書庫から持ってくる。遅く、書庫にも負担がかかる。
  • 机に置ける量は決まっているので、何を残して何を片付けるか（追い出し）が腕の見せ所になる。
  • ここで扱う「物」は、写真や動画の断片のようなデータで、大きさ（サイズ）がまちまちである。小さい物（例 36 KiB）と大きい物（例 1 MiB）が混ざっている。

2. 成績の付け方：OHR と BHR

キャッシュの成績は 2 通りに付けられる。どちらを重く見るかで「良いキャッシュ」が変わる。

指標数え方たとえ効く場面
OHR（物のヒット率）ヒットした要求の数 ÷ 全要求の数「何回、書庫に行かずに済んだか」書庫に行く回数が高くつく（待ち時間・1 回ごとの手数料）
BHR（バイトのヒット率）ヒットした要求のバイト数 ÷ 全要求のバイト数「運ばずに済んだ重さはどれだけか」運ぶ量が高くつく（回線の帯域・転送料金）

OMR = 1 − OHR、BMR = 1 − BHR はそれぞれミスの割合。小さい物をたくさん残すと OHR は上がるが、大きい物を書庫から運ぶ量が増えて BHR は下がりやすい。この 2 つは引っ張り合う。これが全体を通しての大事な点である。

3. 合成ワークロードの作り方

実際の利用記録（トレース）は複雑すぎて、何が効いたのかを切り分けにくい。そこで、サイズが 2〜3 種類しかない、作り物の要求の列を生成した（tools/synth/synth_gen.c）。つまみは 3 つだけである。

  1. サイズの種類と値：例 36 KiB と 1 MiB の 2 種類。
  2. 種類ごとの物の数と、要求の割合：例 小物 20 万個に要求の 75%、大物 2 万個に 25%（3:1）。
  3. 種類ごとの人気の偏り（Zipf の傾き α）。

Zipf（ジップ）分布とは

「1 番人気の物は 2 番人気の物の 2^α 倍、3 番人気の 3^α 倍よく要求される」という人気の偏りの型。順位 r の物の要求率は r^(−α) に比例する。α が大きいほど、一部の人気者に要求が集中する。

要求は 1 回ずつ独立にくじ引きで作る（IRM：独立参照モデル）。まず要求の割合に従って「小物か大物か」を引き、次にその種類の中で Zipf に従って「何番目の物か」を引く。これを 2,000 万回繰り返す。最初の 500 万回はキャッシュを温める期間として成績に入れない。

6. 式①：物の「価値」は λ ÷ s

価値（OHR を上げたいとき） v = λ / s 価値（BHR を上げたいとき） v = λ
記号意味
λ（ラムダ）その物の要求率。1 要求あたり、その物が引かれる確率
sその物の大きさ（バイト）

たとえ：机の 1 cm² あたり、何回「書庫に行かずに済む」か。小さくてよく読まれる本ほど、机の面積あたりの節約が大きい。BHR では節約は重さで数えるので、大きさで割る必要がなく、よく読まれるかどうか（λ）だけで決まる。

数値例（W1）：小物の 1 位は λ = 0.75 × 4.09% = 0.0307、大きさ 36 KiB → 1 KiB あたり 0.00085。大物の 1 位は λ = 0.25 × 5.72% = 0.0143、大きさ 1,024 KiB → 1 KiB あたり 0.000014。同じ 1 位どうしでも、面積あたりの価値は小物が約 61 倍。

7. 式②：Che 近似（物単位の LRU）

LRU（Least Recently Used）は「いちばん長く使われていない物から捨てる」方式。机の上の本を、使った順に並べ直し、いっぱいになったら一番下の本を書庫に戻すイメージ。

Che（チェ）近似は、これを 1 つの数 T で表す。「最後に読まれてから T 要求の間に次の要求が来れば机の上に残っている（ヒット）、来なければ捨てられている（ミス）」と考える。T を特性時間と呼ぶ。

ヒット率 h = 1 − e^{−λT} 容量の式 Σ_i s_i (1 − e^{−λ_i T}) = C （机の上の物の大きさの合計 = 机の広さ）

2 本目の式から T を決め、1 本目に入れて全部の物のヒット率を出す。λ の大きい物ほど T の間に次が来やすいので、ヒット率が高い。

数値例（W1・容量 10%）：T = 18,950 要求。1 万要求に 1 回読まれる物（λ = 10⁻⁴）は h = 1 − e^{−1.9} = 0.85、10 万要求に 1 回の物は h = 0.17。全体で OHR 0.530、BHR 0.593。シミュレーションは 0.530 / 0.593 で、差は 0.01pt。

弱点：全員に同じ T を与えるので、大きい物も小さい物も同じ扱いになる。価値は λ/s なのに、LRU は λ しか見ていない。

8. 式③：サイズで机を仕切る（静的な分割）

机を「小物の棚」と「大物の棚」に仕切り、それぞれで LRU を回す。各棚は自分の T_k を持つ。

棚 k の容量 Σ_{i∈k} s_i (1 − e^{−λ_i T_k}) = C_k, C_1 + C_2 = C 最もよい仕切り方 「容量を 1 バイト増やしたときのヒットの増え方」が全部の棚で等しくなる位置

たとえ：お小遣いの配分。どの使い道に追加の 100 円を回しても嬉しさが同じになるまで配る、のと同じ考え方。これは「棚の境目にいる物の λ/s をそろえる」ことに当たる。BHR を最大にしたいなら、λ をそろえる（式の 1/s を外す）。

数値例（W1・容量 10%）：OHR が最大になるのは、机の 81% を小物に回したとき。OHR 0.530 → 0.688、BHR 0.593 → 0.431。BHR を最大にする仕切り方だと OHR 0.493・BHR 0.594 で、仕切らない LRU とほとんど同じ。上限（λ/s の順に詰めた理想）は OHR 0.768。
→ 仕切らない LRU は BHR についてほぼ最適で、サイズで仕切ると OHR 側に振れる。シミュレーションとの差は 0.3pt 以下。

9. 式④：Region と Region FIFO

フラッシュ SSD は、小さく書き換えるのが苦手で、大きな単位でまとめて消すのが得意である。そこで物を Region（大きな箱）に詰めて書き、捨てるときは箱ごと捨てる。中に人気の物が残っていても一緒に捨てられる（巻き添え）。

Region FIFO は「一番古い箱から順に捨てる」。どの箱も、書いてから同じ時間 T だけ生きる。物から見ると「入ってから T だけ机にいる」ことになる。

ヒット率 h = λT / (1 + λT) （入ってから T の間に来た要求がヒット。捨てられた後の最初の要求でミスして、また入る）

サイズで分けても何も変わらない：小物の箱も大物の箱も同じ T で捨てられるので、誰の扱いも変わらない。シミュレーションでも差は ±0.3pt 以内だった。

数値例（W1・容量 10%）：T = 20,309 要求、OHR 0.486（分類なし・あり、とも）。

10. 式⑤：Region LRU（このモデルの中心）

Region LRU は「一番長く触られていない箱から捨てる」。中のどれか 1 つの物でも読まれると、その箱は「触られた」ことになり、長生きする。

箱の touch 率 Λ = 中の物の λ の和（中の誰かが読まれる頻度） 箱の寿命（平均） L = (e^{ΛT} − 1) / Λ （最後に触られてから T たつと捨てられる） 物のヒット率 h = λL / (1 + λL) （物から見ると「滞在 L の FIFO」）
記号意味
Λ（大文字ラムダ）箱の中の物の要求率の合計
T箱が捨てられるまでの「無アクセスの許容時間」（Che の T の箱版）
L箱が封じられてから捨てられるまでの平均時間

たとえ：箱 = 部屋、物 = 住人。誰か 1 人でも部屋を使えば、部屋は取り壊されない。住人が多く、人気者がいる部屋ほど長持ちする。

サイズで分けると効く理由：小物の箱には物がたくさん（W1・10% で 300 個）入るので Λ が大きく、寿命が指数的に延びる。大物の箱は 10 個しか入らないので短命。結果として、仕切りの割合を決めなくても、机の上が自然に小物に寄る。W1・容量 10% で、小物が占める割合は分類なしの 13% から分類ありの 62% に増える。

数値例（W1・容量 30%、実測）：小物の箱は ΛT ≈ 7.6 で寿命 約 100 万要求（ログで測った平均 101 万）、大物の箱は ΛT ≈ 3.6 で寿命 約 3.6 万要求（ログで測った平均 36,220）。
モデルの精度（全負荷・全容量 24 点）：分類なしの OHR は平均 0.4pt の差。分類ありの OHR は 0.6pt だが、BHR は平均 3.5pt、最大 14pt ずれた。この原因が次の §11。

11. 式⑥：立ち上がりの隔離

空の机から始めると、最初はすべてがミスなので、最初に要求された物、つまり人気者ばかりが最初の箱にまとめて詰まる。この箱は Λ がとても大きく、寿命 e^{ΛT} が実験の長さを超えて事実上「不死」になる。人気者はそこに隔離され、二度とミスしない。

-H（観測期間）：初回の要求の順に物を箱へ詰めて最初の箱を作り、 寿命 (e^{ΛT}−1)/Λ が観測期間 H を超える箱を「不死」とする。 残りの物と残りの容量で §10 の式を解く。
証拠（W3・容量 20%・Region 1,024 個）：終了時に残っていた小物の箱のうち 69 個は、最初の 100 万要求で作られたもの（ΛT = 9〜4,917）。人気 1〜99 位の物は全部、100〜999 位は 900 個中 889 個がその中にいた。
効果：分類ありの BHR のずれが、平均 3.5pt → 0.8pt、最大 14.4pt → 2.6pt。単一サイズで T が実測（5,338）より 25〜40% 短く出ていた謎も解けた（直した後のモデルでは 5,649）。

撤回した診断：最初は「Region の数が有限なので T が揺らぎ、長生きの箱が殺されるのが原因」と考えた。揺らぎの大きさの式 sd(T) = 1/√(2Σ m_i λ_i) は実測と合ったが、箱ごとに寿命を測ると、揺らぎで寿命が縮む効果は見えなかった。本当の原因は上の「隔離」だった。

12. 式⑦：人気が変わる（老化する）ときのモデル　途中経過

人気が少しでも変わると、隔離は消える。一巡時間がトレース長の 4 倍（τ = 8,000 万）というゆっくりした老化でも、最初の箱は終了時に 1 個も残らなかった（老化なしでは小物 26〜59 個）。

老化のモデルでは、物を「年齢 a」（生まれてからの要求数）で表す。順位は r = 1 + a/period、要求率は λ(a) で、年齢とともに下がる。

物単位 LRU 在籍率 = 1 − exp(−∫_{a−T}^{a} λ) （生まれる前は λ = 0 なので、最初の要求は必ずミス） Region LRU 在籍率 p(a) = ∫_0^a λ(a')(1 − p(a')) × [年齢 a' で入った箱が年齢 a まで生きている確率] da' 箱の生存は「中の物の λ の和」で決まり、中の物も一緒に老化する 箱 1 個あたりの「熱い新顔」の数 m はポアソン分布（平均 ν）として、生存確率を m で平均する

たとえ：新入生（新顔）は入ってすぐ大人気で、部屋（箱）に入るとその部屋を長持ちさせる。新入生が何人入るかは部屋によってばらつく（0 人の部屋はすぐ取り壊され、3 人の部屋は長持ちする）。平均の人数で全部の部屋を計算すると、全部の部屋が長持ちすると誤って見積もってしまう。

確定している数値：物単位 LRU の老化モデルは、12 構成すべてで実測と 0.25pt 以内（初回のミスを正しく含む）。単一サイズの Region LRU は OHR 0.730（実測 0.738、−0.9pt）、T 3,745（実測 3,752）。新顔の数のばらつきを入れると、混在の最悪点のずれが −18pt → −3pt。
未確定：全構成での Region LRU の精度は検証中。

13. 結果のまとめ

問い答え根拠
サイズで分けると得かOHR は大きく上がり、BHR は下がるW1 の静的な分割で OHR +14〜18pt、BHR −14〜19pt。Region LRU の分類では OHR +10〜16pt、BHR −2〜8pt（実測）
サイズそのものが効くのか違う。効くのは「価値 λ/s のばらつき」λ/s を両種類でそろえた W2 では、利得が +0.7pt（静的分割）・+0.5pt（Region LRU）に縮む
Region FIFO で分類は効くか効かない全部の箱が同じ時間で捨てられる。実測 ±0.3pt
式で予測できるかできる物 LRU 0.01pt、静的分割 0.02pt、Region LRU（隔離あり）OHR 0.2pt・BHR 0.1〜0.8pt（平均）
人気の偏りの形は効くか小物の人気が平らなほど分類が効くW3r（小物 α=0.6）で静的分割 +27pt（容量 20%）、W3（小物 α=1.1）で +10pt（容量 10%）
3 種類に分ける意味は小さいW5 で 3 分割の上乗せは最良の 2 分割に対して +1.8pt（モデル）
人気が変わると隔離は消える。Region の損失は物 LRU の 2〜4 倍。分類の利得は残るW1・30% の老化による損失：物 LRU −0.2 / −0.7 / −2.9pt、Region LRU（分類あり）−0.8 / −2.6 / −6.2pt。分類の利得 +16.7pt（τ=8,000 万）、+13.4pt（τ=500 万）
